# Window Switcher 1.0.0

Initial public release of Window Switcher, a macOS window switcher that replaces the standard Command+Tab workflow.

## Highlights

- Switch between individual windows, including multiple windows from the same app.
- Recent-use ordering with reverse cycling through Shift+Command+Tab.
- Delayed overlay for quick Command+Tab switching.
- App icon, app name, and window title in the selector.
- Mouse selection from the selector.
- Filtering for the current display and Space, with Stage Manager support.
- Modal, sheet, dialog, and transient popup filtering.
- Screen Sharing passthrough only while the Screen Sharing window is full screen.

## Requirements

- macOS 13 or later.
- Accessibility permission for Window Switcher to intercept Command+Tab and focus windows.

The release archive is locally signed for development use and is not notarized with an Apple Developer ID certificate.
