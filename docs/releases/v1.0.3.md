# Window Switcher 1.0.3

## Improvements

- Package the application in a DMG with an `Applications` shortcut for drag-and-drop installation.
- Add `build-dmg.sh` to generate the local signed DMG under `dist/`.

## Requirements

- macOS 13 or later.
- Accessibility permission for Window Switcher to intercept Command+Tab and focus windows.

The DMG is locally signed for development use and is not notarized with an Apple Developer ID certificate.
