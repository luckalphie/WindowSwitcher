# Window Switcher 1.0.1

## Fixes

- Keep the switchable-window list consistent when Stage Manager is enabled or disabled.
- Preserve independent identities and MRU ordering for multiple windows in the same application, including overlapping or same-size windows.
- Correct recent-window selection after changing focus between windows in the same application.
- Constrain a long window list to the active display's visible height and make it scrollable.
- Use a stable local code-signing identity for packaged builds so macOS Accessibility permission can persist across rebuilds.

## Requirements

- macOS 13 or later.
- Accessibility permission for Window Switcher to intercept Command+Tab and focus windows.

The release archive is locally signed for development use and is not notarized with an Apple Developer ID certificate.
