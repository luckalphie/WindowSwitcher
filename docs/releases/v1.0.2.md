# Window Switcher 1.0.2

## Improvements

- Recover the global keyboard event tap automatically after macOS disables it because of a timeout or user input.
- Split the Swift source by responsibility: application coordination, window discovery, activation, UI, and models.
- Add Chinese comments for macOS-specific concepts such as Accessibility objects, event taps, MRU state, and keyboard-switch sessions.
- Store local application bundles and disk images under `dist/` instead of the repository root.

## Requirements

- macOS 13 or later.
- Accessibility permission for Window Switcher to intercept Command+Tab and focus windows.

The DMG is locally signed for development use and is not notarized with an Apple Developer ID certificate.
