# Window Switcher 1.0.4

## Improvements

- Track window focus changes to improve recent-window ordering when switching with the mouse.
- Read back the actual focused window after a switch rather than assuming the focus request succeeded.
- Add a menu option to launch Window Switcher at login.
- Let macOS handle Command+Tab while a full-screen application is frontmost.
- Filter DBeaver-style dialogs that are not marked as modal by Accessibility.
- Remove the unnecessary Screen Recording settings shortcut.

## Requirements and limitations

- macOS 13 or later on Apple Silicon.
- Accessibility permission is required to intercept Command+Tab and focus windows.
- Some applications may not send Accessibility focus notifications, so intermediate mouse focus changes may not be recorded.
- The focus-order changes have been built but have not yet been validated through interactive desktop testing across Stage Manager and multiple windows.

The DMG is locally signed for development use and is not notarized with an Apple Developer ID certificate.
